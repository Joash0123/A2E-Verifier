# A2E Verifier — Creative Frontend

A visual rebuild for the A2E Verifier project.

## Run
```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

The Vite dev server proxies `/api/*` to the existing FastAPI server at `http://127.0.0.1:8000`.

## Design direction
Inspired by the uploaded reference's high-contrast editorial/experimental motion language:
- oversized typography
- dark immersive canvas
- acid-green security accent + restrained warm warning accent
- animated geometric verification object
- scrolling marquee
- editorial sections
- functional verifier UI
- deterministic backend remains the security decision-maker

The implementation uses original UI, copy, shapes and effects rather than copying the reference site's proprietary assets.
